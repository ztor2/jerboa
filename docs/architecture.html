Single Decoder Layer Anatomy Pre-RMSNorm + Residuals
① Grouped-Query Attention (GQA 3:1) + QK-Norm
• 12 Query Heads : 4 KV Heads (66.7% KV memory reduction)
• QK-Norm: Per-head RMSNorm on Q and K vectors prior to dot product (prevents entropy collapse)
• Kernel: Native PyTorch SDPA accelerated by Metal Performance Shaders (MPS)

② SwiGLU Feed-Forward Network (FFN)
• Expansion: 768 → 2,048 ($d_{ffn} \approx 2.67 \times d_{model}$)
• Formula: (SiLU(x · W_gate) ⊗ (x · W_up)) · W_down
• Output: Projects back to 768 hidden dimensions
